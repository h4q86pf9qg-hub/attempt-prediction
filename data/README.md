# Данные

Данные синтетические: сгенерированы для учебного ML-симулятора онлайн-школы (ЕГЭ). Не содержат персональных данных.

## `raw/tasks.csv`
Справочник задач.

| Колонка | Описание |
|---|---|
| `task_id` | ID задачи |
| `topic` | Тема (например, `equations`, `probability_basic`) |
| `subject` | Предмет (`math`, `russian`, `physics`) |
| `declared_difficulty` | Заявленная сложность задачи |
| `max_points` | Максимальный балл за задачу |
| `ege_task_no` | Номер задания ЕГЭ |
| `task_type` | Тип задачи |
| `statement` | Условие задачи |
| `reference_solution` | Эталонное решение |

## `clean/attempts.csv`
Очищенные попытки решения задач.

| Колонка | Описание |
|---|---|
| `attempt_id` | ID попытки |
| `student_id` | ID ученика |
| `task_id` | ID задачи |
| `ts` | Время попытки (datetime) |
| `is_correct` | Целевая переменная: 1 — решено верно, 0 — ошибка |
| `time_sec` | Время решения, сек |
| `hints_used` | Число использованных подсказок |
| `source` | Источник задачи (`self_practice` или `homework`) |
| `error_type` | Тип ошибки (если есть) |

## Очистка

Логика очистки вынесена в [`src/cleaning.py`](../src/cleaning.py):
- приводятся два формата дат (`DD.MM.YYYY HH:MM:SS` и `YYYY-MM-DD HH:MM:SS`);
- удаляются дубликаты по `attempt_id`;
- служебные значения `time_sec` (`-5`, `0`, `86400`, `99999`) заменяются на пропуски.
