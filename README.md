# Attempt Prediction — предсказание правильности решения задачи

ML-проект на синтетических данных онлайн-школы: по истории попыток ученика предсказываем вероятность того, что очередная попытка решения задачи будет правильной.

**Зачем это нужно:**
- подбирать ученику задачи с вероятностью ошибки около 50% (не слишком лёгкие и не слишком сложные);
- заранее сигнализировать преподавателю о росте вероятности ошибок.

## Данные

Синтетические данные онлайн-школы (ЕГЭ). Подробное описание колонок — в [`data/README.md`](data/README.md).

- `data/raw/tasks.csv` — справочник задач (тема, предмет, сложность).
- `data/clean/attempts.csv` — очищенные попытки решения задач.

## Подход

1. **Разбиение по времени:** обучение — недели 0–27, тест — недели 28 и позже. Случайный сплит здесь нечестен: модель не должна видеть будущее.
2. **Feature engineering:** историческая точность ученика до начала текущей недели (`hist_acc`), число предыдущих попыток и правильных ответов, признаки задачи (тема, предмет, заявленная сложность).
3. **Модели:** логистическая регрессия и gradient boosting. Сравнение с бейзлайнами (константа, средняя точность по задаче, средняя точность по ученику).
4. **Исключены post-hoc признаки:** `time_sec` и `hints_used` известны только после попытки, поэтому в финальной модели их нет.

## Результаты на тесте (недели ≥ 28)

| Модель | ROC-AUC | LogLoss |
|---|---|---|
| Константа | 0.500 | 0.676 |
| Средняя точность по задаче | 0.629 | 0.650 |
| Средняя точность по ученику | 0.658 | 0.640 |
| Logistic Regression | 0.706 | 0.608 |
| **Gradient Boosting** | **0.710** | **0.604** |

Главные признаки по permutation importance — `hist_acc` и `declared_difficulty`. Калибровочная кривая близка к диагонали в средней части диапазона; на краях есть отклонения, для точных порогов потребуется дополнительная калибровка.
